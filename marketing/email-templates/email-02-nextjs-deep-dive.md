## ¿Sabías que puedes tener una app AI full-stack lista en 5 minutos?

Con el **Next.js AI Starter Kit**, puedes tener una aplicación completa con:
- Chat con OpenAI GPT-4
- Autenticación con Auth.js
- Pagos con Stripe
- Despliegue en Vercel

### Demo rápida:

```bash
npx degit miguelabarca/nextjs-ai-starter my-ai-app
cd my-ai-app
npm install
npm run setup  # Configura OpenAI, Auth, Stripe
npm run dev    # ¡Listo! Abre http://localhost:3000
```

### Características:
- ✅ Chat UI con streaming de respuestas
