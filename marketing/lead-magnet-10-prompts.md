# 10 Prompts de IA para Desarrolladores (Gratis)

**Optimizados para GPT-4, Claude 3 y Gemini Pro**

---

## Prompt 1: Generación de Código
Actúa como un desarrollador senior experto en {lenguaje/framework}. Genera un {tipo de componente/función} que {descripción}. Incluye manejo de errores, logging y sigue las mejores prácticas de {lenguaje/framework}.

## Prompt 2: Code Review
Revisa el siguiente código como un desarrollador senior. Identifica:
1. Problemas de seguridad
2. Mejoras de rendimiento
3. Code smells
4. Tests faltantes
Sugiere cambios específicos y explica por qué.

## Prompt 3: Debugging Asistido
Tengo este error: {mensaje de error}. Este es mi código: {código}. Explícame qué causa el error y dame 3 posibles soluciones ordenadas por probabilidad de éxito.

## Prompt 4: Documentación Automática
Genera documentación completa para el siguiente código siguiendo el formato JSDoc/TSDoc. Incluye descripción del propósito, parámetros, valores de retorno, ejemplos de uso y edge cases.

## Prompt 5: Refactorización
Refactoriza el siguiente código para mejorarlo en: legibilidad, rendimiento, mantenibilidad y testabilidad. Explica cada cambio y por qué mejora el código.

## Prompt 6: Tests Unitarios
Genera tests unitarios para el siguiente código usando {framework de tests}. Cubre: casos normales, edge cases, errores, y mocks necesarios. Sigue el patrón Arrange-Act-Assert.

## Prompt 7: Explicación Técnica
Explica {concepto técnico} como si se lo estuvieras enseñando a un desarrollador junior. Incluye: qué es, cómo funciona, cuándo usarlo, ventajas/desventajas, y un ejemplo práctico en {lenguaje}.

## Prompt 8: Base de Datos y Queries
Dado el siguiente esquema de base de datos: {esquema}, escribe una query optimizada para {requerimiento}. Explica por qué esta query es eficiente y qué índices recomendarías.

## Prompt 9: DevOps y CI/CD
Diseña un pipeline de CI/CD para un proyecto {tipo de proyecto} usando {herramientas}. Incluye: linting, tests, build, deploy, y rollback strategy. Explica cada etapa y por qué es necesaria.

## Prompt 10: System Design
Diseña la arquitectura de un sistema que {descripción del sistema}. Cúbre: componentes, flujo de datos, almacenamiento, escalabilidad, y trade-offs. Usa un diagrama en texto y explica cada decisión.
