# RAG System Template — QA sobre Documentos con LangChain

**Precio:** $39 | **Categoría:** Herramientas de Desarrollo

## 🚀 ¿Qué incluye?

Sistema RAG (Retrieval-Augmented Generation) listo para producción:

- **LangChain/LlamaIndex** integración completa
- **ChromaDB + PostgreSQL (pgvector)** para embeddings
- **FastAPI** con streaming y WebSockets
- **Docker Compose** listo para deploy
- **3 estrategias de chunking** (fixed, semantic, recursive)
- **Multi-modelo** (OpenAI, Anthropic, Gemini, Ollama)
- **UI** con Next.js 15 + chat stream

## 🔥 ¿Por qué comprar esto?

- RAG es la tendencia #1 en IA empresarial 2026
- Implementación probada en producción
- Soporta PDF, Word, TXT, HTML, Markdown
- Cache inteligente de embeddings
