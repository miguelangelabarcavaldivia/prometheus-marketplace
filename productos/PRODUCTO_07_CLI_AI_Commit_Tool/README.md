# CLI AI Commit + Code Review Assistant

**Precio:** $14 | **Categoría:** Herramientas de Desarrollo

## 🚀 ¿Qué incluye?

CLI tool que genera commits y code reviews con IA:

### Comandos
```
aicommit generate    # Genera mensaje de commit desde git diff
aicommit review      # Code review del último commit
aicommit suggest     # Sugiere mejoras de código
aicommit changelog   # Genera changelog desde commits recientes
```

### Features
- **Multi-modelo** — OpenAI, Anthropic, Gemini (configurable)
- **Modos** — Conventional commits, emoji, personalizado
- **Integración** — Husky, GitHub Actions, VS Code
- **Configurable** — `.aicommitrc` file, templates personalizados

## 🔥 ¿Por qué comprar esto?

- Commits profesionales en segundos
- Code reviews automáticos antes de cada push
- Ahorra 5h/semana en tareas de git y code review
