## ¿Qué es esto?

Este playbook contiene **más de 200 prompts de producción** organizados por categoría para que cualquier desarrollador pueda aprovechar la IA generativa en su trabajo diario. Cada prompt ha sido diseñado, probado y refinado para producir resultados consistentes y de alta calidad.

No son prompts genéricos. Son prompts específicos para tareas reales de desarrollo de software, con variables reemplazables, formatos de salida esperados y ejemplos concretos.

## Cómo Usar Este Playbook

Consulta la **[guía rápida](guia-rapida.md)** para instrucciones detalladas.

En resumen:

1. **Navega** por las categorías según tu necesidad
2. **Reemplaza** las `{variables}` con tu contexto específico
3. **Copia y pega** el prompt en tu IA preferida
4. **Revisa** el resultado y ajústalo según necesites
5. **Itera** combinando múltiples prompts del playbook
