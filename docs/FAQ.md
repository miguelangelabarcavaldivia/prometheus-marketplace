# Preguntas Frecuentes (FAQ)

## General

### ¿Qué es Prometheus IA Dev Marketplace?
Una colección de 7 productos AI diseñados específicamente para desarrolladores. Desde starter kits hasta agentes autónomos, cada producto está construido para ponerte productivo en minutos.

### ¿Necesito experiencia previa en AI?
No. Los starter kits y plantillas están diseñados para ser plug-and-play. Si sabes usar la terminal y tienes una cuenta de OpenAI, puedes empezar hoy.

### ¿Cómo recibo los productos?
Al comprar, recibes un enlace de descarga inmediato por email y en tu cuenta de Gumroad. Los archivos vienen en formato ZIP con instrucciones de instalación.

### ¿Ofrecen reembolsos?
Sí. Gumroad ofrece reembolsos completos si no estás satisfecho en 7 días. No hay preguntas.

## Técnico

### ¿Qué versión de Node.js necesito?
Node.js 20+ para todos los productos. Algunos requieren Node.js 22+ para características modernas.

### ¿Puedo usar estos productos con mi proveedor de AI favorito?
Sí. El CLI AI Commit Tool soporta OpenAI, Anthropic (Claude), Groq, y Google (Gemini). Los otros productos están configurados para OpenAI por defecto pero son fácilmente configurables para otros proveedores.

### ¿Los productos funcionan en Windows/Mac/Linux?
Sí. Todos los productos son multiplataforma. El CLI tool funciona en Windows, Mac, y Linux. El Next.js Starter Kit funciona en cualquier plataforma con Node.js.

### ¿Necesito Docker?
Docker es opcional pero recomendado para el AI Agent Pipeline. Los otros productos funcionan sin Docker.

### ¿Cómo configuro mi API key de OpenAI?
Crea un archivo `.env` en el directorio del producto con:
```
OPENAI_API_KEY=sk-tu-api-key-aqui
```

## Precios y pagos

### ¿Por qué los precios están en centavos?
Gumroad maneja precios en centavos para evitar problemas de coma flotante. $49 = 4900 centavos.

### ¿Puedo pagar con criptomonedas?
Gumroad soporta Pagamento con criptomonedas a través de su checkout.

### ¿Hay facturación para empresas?
Sí. Gumroad genera facturas automáticamente. Si necesitas factura con IVA, contacta a miguel@prometheus-ia.dev.

## Bundles

### ¿Qué es un bundle?
Un bundle es un paquete de 2-3 productos vendidos juntos con descuento. Por ejemplo, el Full Stack AI Bundle incluye Next.js AI Starter Kit + RAG System + AI Agent Pipeline.

### ¿Puedo usar los productos del bundle por separado?
Sí. Cada producto en el bundle se puede usar independientemente. El bundle es solo una forma de ahorrar dinero.

### ¿Los bundles incluyen actualizaciones futuras?
Sí. Todas las actualizaciones futuras de los productos incluidos en el bundle están incluidas.
